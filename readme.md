# Applied Machine Learning

Course repository for ** Applied Machine Learning**, containing unit-wise implementations as Google Colab notebooks.

## 📌 About the Course

This repository accompanies the Applied Machine Learning course and provides hands-on implementations for each unit of the syllabus using Python (NumPy, Pandas, Scikit-learn, Matplotlib/Seaborn, and TensorFlow/Keras or PyTorch where applicable). Each unit's notebook can be run directly in Google Colab — no local setup required.

## 🚀 How to Run

Each notebook includes an **"Open in Colab"** badge at the top. Click it to launch the notebook directly in your browser — no installation required.

To run locally instead:

```bash
git clone https://github.com/<your-username>/20ITEL705-Applied-Machine-Learning.git
cd 20ITEL705-Applied-Machine-Learning
pip install -r requirements.txt
jupyter notebook
```
